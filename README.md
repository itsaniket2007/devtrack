# devtrack
A personal developer productivity and learning tracker built with Python, continuously evolving as I learn new concepts and technologies.

## Task deadlines

Choose **9. View Task Deadlines** from the menu to see incomplete tasks that
are overdue, due today, or due within the next seven days. Tasks are ordered
by their due date within each group.

## Testing

Run the deadline dashboard tests with:

```bash
python -m unittest discover -s tests -v
```
